# ESEB STORY 상징 이미지 레퍼런스

## 팬던트

- 세브가 잠들며 몸을 둥글게 웅크린 알 형태 자체가 팬던트다.
- 세브가 별도의 케이스 안으로 들어가는 설정이 아니다.

## 목걸이

- 목걸이는 팬던트를 보관하고 착용하는 장치다.
- 금빛 그물·새장 같은 구조는 목걸이 또는 팬던트 고정 장식으로 표현할 수 있다.

## 알 형태

- 큰 날개와 꼬리로 몸 전체를 감싼 세브의 수면 자세
- 이야기의 끝과 시작, 순환을 상징하는 대표 이미지

## 로고

- ESEB = ES(Eun Seong) + EB(Eun Bin)
- SEB는 세브와 연결되는 숨은 언어유희로 사용할 수 있다.

과거 채팅에서 제작된 팬던트·알 형태·로고 이미지 원본은 아직 업로드되지 않았다.
