# ESEB STORY 레퍼런스 자료 관리

이 폴더는 ESEB STORY의 이미지·색상·상징·세계관 시각 자료를 보관하는 공식 레퍼런스 영역이다.

## 운영 원칙

1. MASTER_BIBLE은 텍스트 기준의 최신 공식 설정집이다.
2. REFERENCE는 실제 이미지와 시각 자료의 원본·후보·폐기 이력을 보관한다.
3. 이미지 파일은 캐릭터, 세계, 상징, 색상 기준으로 나눈다.
4. 공식 채택 자료는 `official/`, 검토 중 자료는 `concept/`, 폐기·구버전은 `legacy/`에 둔다.
5. 과거 채팅에 올린 이미지는 원본 파일을 다시 확보한 뒤 업로드한다.
6. 새 이미지가 등록되면 MASTER_BIBLE의 디자인 기준 항목에서 해당 경로를 연결한다.

## 현재 상태

- 구조와 운영 기준만 생성됨.
- 과거 채팅 이미지 원본은 아직 업로드되지 않음.
- 앞으로 다시 첨부되는 자료부터 파일명과 버전을 붙여 관리한다.
