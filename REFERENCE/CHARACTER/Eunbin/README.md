# 김은빈 이미지 레퍼런스

## 기본 기준

- 은성편 1부의 핵심 동행자
- 첫 에피소드: 미래 10세 은빈
- 두 번째 에피소드 이후: 미래 5세 은빈
- 은빈편 시작 시점: 6세
- 나이별 디자인은 서로 구분하되 같은 인물임을 느낄 수 있는 공통 표정·습관·인상을 유지

## 분류

- `official/`: 공식 채택 이미지
- `concept/`: 검토 중인 나이별 캐릭터화·의상·표정 자료
- `legacy/`: 폐기·구버전 자료

## 업로드 대기

과거 채팅에서 제공된 은빈 사진과 5세·10세 캐릭터 이미지 원본은 아직 업로드되지 않았다. 원본 확보 후 연령별 폴더와 버전으로 나누어 관리한다.
