# 세브(SEB) 이미지 레퍼런스

## 공식 디자인 기준

- 작은 하얀 용
- 흰색·진주빛 몸
- 유니콘과 드래곤 요소
- 천사 날개와 불사조 깃털 느낌
- 큰 귀
- 푸른 보석
- 보랏빛·오로라 계열 포인트
- 금빛은 몸색이 아니라 장식·빛·목걸이 구조에 사용
- 평상시 크기는 손바닥 정도
- 잠들면 몸을 둥글게 웅크려 알 형태의 팬던트가 됨

## 분류

- `official/`: 공식 채택 이미지
- `concept/`: 검토 중인 디자인
- `legacy/`: 금빛 용 등 폐기·구버전 이미지

## 업로드 대기

과거 채팅에서 제작·첨부된 세브 이미지 원본은 아직 이 저장소에 업로드되지 않았다. 원본 확보 후 파일별로 버전과 용도를 기록한다.
