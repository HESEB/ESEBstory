# 김은성 이미지 레퍼런스

## 기본 기준

- 은성편 전체의 주인공
- 1부 기준 6~7세
- 현실적인 유치원생의 표정과 행동
- 모험 속에서도 지나치게 완성된 영웅처럼 표현하지 않음
- 고민, 망설임, 실수, 선택, 성장이 얼굴과 자세에 드러나야 함

## 분류

- `official/`: 공식 채택 이미지
- `concept/`: 검토 중인 캐릭터화·의상·표정 자료
- `legacy/`: 폐기·구버전 자료

## 업로드 대기

과거 채팅에서 제공된 은성 사진 및 캐릭터 이미지 원본은 아직 업로드되지 않았다. 원본 확보 후 실제 인물 참고자료와 창작 캐릭터 이미지를 구분해 관리한다.
