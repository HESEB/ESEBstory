# 물총왕국 이미지 레퍼런스

## 공식 명칭

- 물총왕국
- `물총나라`는 공식 명칭으로 사용하지 않는다.

## 핵심 배경 요소

- 하늘에 떠다니는 거대한 물방울
- 산호와 조개집
- 하늘을 향해 흐르는 물줄기
- 어인족 아이들이 살아가는 세계
- 물총 경기와 협력 관문
