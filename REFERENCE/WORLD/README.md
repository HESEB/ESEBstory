# ESEB STORY 세계 이미지 레퍼런스

각 권과 에피소드의 세계 이미지, 지도, 배경 콘셉트, 종족 디자인을 보관한다.

## 기본 원칙

- 모든 모험이 하나의 고정 세계에서 이어지는 구조가 아니다.
- 각 현실 고민과 감정에 맞닿은 별도의 세계를 시각화한다.
- 공식 원고에 등장한 명칭을 우선 사용한다.
- 공식 채택 자료와 아이디어 이미지를 구분한다.

## 기본 분류

- `WaterKingdom/`: 4권 물총왕국
- `InsectWorld/`: 곤충 세계
- `DinosaurWorld/`: 공룡 세계
- `OrigamiWorld/`: 종이접기 세계
- `RobotWorld/`: 로봇 세계
- `OtherWorlds/`: 추가·미확정 세계

각 세계 폴더는 향후 `official/`, `concept/`, `legacy/` 구조로 확장한다.
